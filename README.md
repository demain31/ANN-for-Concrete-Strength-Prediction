## 🚀 How to Run

### 1. Run Locally
The repository includes all necessary files (`data/`, `scaler/`, and `model/`) to run everything offline:
- Open `ann-for-concrete-strength-prediction-v1.ipynb` in VS Code or Jupyter.
- Run all cells.

> **Note:** Local scores match the Kaggle results up to two decimal places. Any tiny difference in the third decimal is just rounding across machines.

### 2. Run on Kaggle
You can also run the original notebook in one click:
